# DropLink 🚀

**Simple, fast, and secure peer-to-peer file sharing.**

DropLink lets you share files between devices directly using a six-digit connection code or QR code.

## ✨ Features

- 📁 Send and receive multiple files
- 🔗 Connect using a six-digit code
- 📷 Scan QR codes to connect
- ✅ Accept or reject connection requests
- ⏸️ Pause, resume, and cancel transfers
- 📊 Real-time transfer progress
- 📱 Responsive mobile-friendly design
- 🕘 Transfer history

## 🔒 Privacy

DropLink uses WebRTC for direct peer-to-peer file transfers. Files are not uploaded to cloud storage by the app.

## ⚠️ Note

Transfer speed and reliability depend on your internet connection, browser, and devices. A TURN server may be needed for connections across restrictive networks.
